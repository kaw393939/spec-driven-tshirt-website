# Same shirt. Different story.

An intro web-development studio: give the same plain white T-shirt meaning for an audience through brand archetypes, Cialdini, modernist/postmodernist visual exploration, and critique. Express the chosen brand in a browser-only site using shared specs and AI.

**[Open the student hub](https://kaw393939.github.io/spec-driven-tshirt-website/docs/)** · **[Start the brand brief](https://kaw393939.github.io/spec-driven-tshirt-website/docs/brand-strategy.html)**

## The assignment

One product, different sizes, HTML/CSS/plain JavaScript, and a simulated cart/checkout. GitHub Pages serves the files. No backend, database, real payment, or personal-data collection.

Students create a brand brief, compare two annotated visual directions, apply two Cialdini principles, get peer critique, revise their chosen direction, and plan discovery/promotion. They also observe served files and browser event/state/DOM changes in a learning lab. They write checks, get peer feedback, review AI’s changes, and link each spec to its issue, commit, PR, and result.

**Status: revised planning baseline; human approval pending. No storefront implementation yet.** The root homepage is still a blank placeholder with a Documentation footer link. The docs hub includes interactive teaching aids, not a completed storefront.
