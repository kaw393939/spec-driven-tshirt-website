# Contributor instructions

- This repository is in documentation/specification approval phase. Do not create application code, install application dependencies, scaffold frameworks, or deploy before M0 passes.
- Documentation hosting on GitHub Pages and the footer-only placeholder homepage are authorized before M0. This exception does not approve e-commerce application code.
- Read README.md, docs/approval.md, approved specifications, and the linked issue before changes. Pending documents are proposals.
- Documentation is the source of truth. Propose requirement changes in a reviewed PR before implementing changed behavior.
- Use one issue-focused branch and atomic commits referencing issue numbers. Link requirement IDs, acceptance IDs, tests and evidence in the PR and traceability matrix.
- AI may draft or review; a human owns acceptance. Never invent approvals, test runs, customer reviews, claims, credentials, or evidence.
- Record material AI assistance in PRs. Keep secrets and personal data out of prompts, commits and fixtures.
